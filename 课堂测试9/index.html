课堂任务交付记录

任务一 · 提示词工程师 ⭐⭐

需求拆解：① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停止 ③ 圆点分页器可点击 ④ 初始效果 cube。

第 1 轮提示词

用 Swiper 11 给 #lsySw4 写一份轮播配置：要循环播放，要自动播放，带圆点分页器，效果用 cube。

第 1 轮 AI 输出（节选）

new Swiper('#lsySw4', {
  loop: true,
  autoplay: true,
  effect: 'cube',
  pagination: '.swiper-pagination'
});

问题诊断

  • 漏了 delay: 3200，自动播放会按默认 3000ms 走，不是 3.2 秒。
  • 漏了 disableOnInteraction: false，这是 Swiper 的默认行为，用户一拖动自动播放就停了。
  • pagination 只写了字符串选择器，没有 clickable: true，圆点点了不跳转。

第 2 轮提示词（把需求逐条编号，要求逐条对应）

请严格按 4 条硬需求输出配置，并逐条编号说明：① loop 为 true 实现无缝循环； ② autoplay.delay 为 3200，且用户拖动后自动播放不停止；③ 分页器绑定到 #lsyPag4 且圆点可点击；④ effect 初始为 cube，并给出 cubeEffect 的立体阴影配置。 只输出 new Swiper 的配置对象，不要多余解释，最后用表格把每个参数对应到需求编号。

第 2 轮 AI 输出

new Swiper('#lsySw4', {
  loop: true,                                   // 需求① 无缝循环
  autoplay: {
    delay: 3200,                                // 需求② 每 3.2 秒翻页
    disableOnInteraction: false                 // 需求② 拖动后继续自动播放
  },
  pagination: { el: '#lsyPag4', clickable: true }, // 需求③ 圆点可点击
  effect: 'cube',                               // 需求④ 初始立方体
  cubeEffect: { shadow: true, slideShadows: true },
  speed: 800
});

验证结论

  • 循环：最后一张继续向后翻回到第一张，无缝 ✔
  • 自动播放：实测约 3.2 秒翻一页，拖动再松手后仍继续自动播放 ✔
  • 分页器：点击任意圆点直接跳到对应展品 ✔
  • 初始效果：打开页面即为立方体翻转，且每张带阴影 ✔

答辩预演：第一版提示词漏掉了「3.2 秒」和「拖动后不停」两个细节，把 autoplay 草草写成 true；第二轮改成逐条编号需求、并把参数名直接写进提示词，AI 才逐项对齐。 这说明提示词越具体，返工越少。

任务二 · creative 电影墙 ⭐⭐⭐

在演示四新增第 7 个按钮，用课堂未讲解的 creativeEffect 实现电影选片墙效果。 

creativeEffect: {
  // 上一张：缩小、左移、向后 240px、绕 Y 轴转 26 度
  prev: {
    translate: ['-38%', 0, -240],
    rotate: [0, 26, 0],
    scale: 0.72,
    opacity: 0.55
  },
  // 下一张：放大到 0.86、右移、向后 240px、反方向转 18 度
  next: {
    translate: ['42%', 0, -240],
    rotate: [0, -18, 0],
    scale: 0.86,
    opacity: 0.55
  }
}

prev / next 的 transform 各控制什么？

  • prev 描述「还没轮到、停在左边待命的那一张」的状态：向左让位、缩小、压暗，形成纵深。
  • next 描述「即将进场、停在右边的那一张」的状态：向右让位、略大、反方向倾斜，作为接棒的下一幕。
  • 当前这张始终在正中间，creativeEffect 只负责前后两张怎么「退场」和「候场」。
  • translate 的百分比相对 slide 自身宽高，第三个数是 Z 轴的像素值（负数代表往屏幕里退）。
  • rotate 是 [x, y, z] 三个轴的旋转角度，想让卡片歪 20 度，改 rotate 第二个值即可（如 [0, 20, 0]）。

现场可验证：演示四的按钮下方有一个「卡片倾斜角度」滑块， 切到 creative 后拖动它，就能实时看到 prev.rotate[1] 与 next.rotate[1] 变化带来的倾斜效果； 拖到 20° 即对应答辩要求。

任务三 · 综合创作 + 超纲能力 ⭐⭐⭐

新增第六件展品「爱达·魔都号」（同时加入演示四与展品墙），并在展品墙加入课堂没讲过的 keyboard 键盘控制。 

var lsyGallerySwiper = new Swiper('#lsyGallerySw', {
  loop: true,
  speed: 700,
  slidesPerView: 1.15,
  spaceBetween: 18,
  keyboard: { enabled: true, onlyInViewport: true }, // 超纲能力：← / → 切换
  pagination: { el: '#lsyGalleryPag', clickable: true },
  navigation: { nextEl: '#lsyGalleryNext', prevEl: '#lsyGalleryPrev' },
  breakpoints: {
    880: { slidesPerView: 2.15, spaceBetween: 24 }
  }
});

三点说明

  • keyboard.enabled 开启键盘控制，默认方向键 ← / → 就是上一个 / 下一个。
  • onlyInViewport: true 表示轮播不在可视区域时按键不生效，避免和页面滚动抢事件。
  • 键盘事件绑定在轮播容器上，所以容器需要 tabindex="0" 才能获得焦点，点击轮播即可聚焦。

与 AI 的关键对话记录

第 1 轮提示词

我给一个 Swiper 11 轮播加键盘控制，用 ← / → 切换上一张和下一张，需要哪些配置？ 顺便说明为什么有时按键没反应。

AI 回答（节选）

加 keyboard: { enabled: true }，Swiper 会自动监听容器的键盘事件； 如果按键没反应，通常是因为容器没有获得焦点。

我的追问

只写 keyboard: true 和写成对象的区别是什么？只想在轮播出现在屏幕里时才响应按键，该怎么写？

AI 回答（节选）

对象写法更明确，并且可以加 onlyInViewport: true； 布尔写法无法关闭这个开关，不同版本兼容性也不一致。

验证与改动

  • 第一版直接贴上 AI 代码，按键没反应——原因是 AI 没提醒容器要能获得焦点。
  • 我给容器补了 tabindex="0"，并加了「点击轮播自动聚焦」的 JS，实测 ← / → 可切换且页面不滚动 ✔

答辩四连问 · 我的回答

  • 这段代码什么意思：开启后 Swiper 监听容器键盘事件，← 调用 slidePrev()、→ 调用 slideNext()；onlyInViewport 让没出现在屏幕里的轮播不响应按键。
  • AI 第一次哪里不对、我改了什么：漏了 tabindex，容器拿不到焦点所以按键无效；我补上 tabindex="0" 并绑定点击聚焦。
  • 新参数的作用：enabled 是键盘控制的开关，onlyInViewport 限制只在可视区域内生效。
  • 现场把 delay 改成 5000：每 5 秒才翻一页，翻页变慢；loop、分页器、导航按钮都不受影响。

现场改参数预演：把 autoplay.delay 从 3200 改成 5000， 预期是每张停留时间变长、翻页变慢，其他行为不变。
